# 反馈与贡献 / Feedback

源码：https://github.com/SimpleAI2026/SimpleTools

## 中文

欢迎用 GitHub Issue 提交可复现的缺陷或具体建议。请写上：页面或工具地址、界面语言、浏览器或扩展环境、操作步骤、实际结果和期望结果。能附上的报错文本或截图请一并附上。不要在 Issue 里粘贴密钥。

如果你愿意附上修改，请从默认分支开独立分支，并说明怎样复现、怎样验证。本项目允许自由分发。

本地检查可以用 `./build.sh test`、`./build.sh lint` 和 `./build.sh build`。完整编程运行时不在普通构建里，见 README 对 `../SimpleCode` 的说明。

## English

GitHub Issues are the place for reproducible bugs and concrete suggestions. Include the page or tool URL, UI language, browser or extension host, steps, actual result, and expected result. Add error text or a screenshot when you have one. Do not paste API keys.

A patch can start from the default branch on its own branch, with the reproduction and the check you ran. This project may be freely distributed.

Local checks: `./build.sh test`, `./build.sh lint`, and `./build.sh build`. A normal build does not include the full programming runtimes; see the README note about `../SimpleCode`.
